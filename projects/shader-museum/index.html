Shader Musuem

Tags: Shaders, Seasonal Effects, HLSL Software: Unreal Engine
Project Total Time: 2 weeks

This project is being optimised currently with HLSL.

The Problem

For teaching purposes I needed to create a level where a bunch of easy to adjust shaders could be found for students to experiment with, primarily for enviroment artists. This evolved into a “museum” space for easier display and walkthrough using game view.

How I Made It

I used Unreal Engines shader node network to build out each shader from various master materials. I went with the winter theme as snow, ice and moss had good masking effects that could be reused on other materials. Ice also posed a complex challenge on how to present more costly and accurate solutions versus a simpler cheaper one. Whilst satisfied I definitely want to redo this project to a much higher standard as blending is very sharp amongst a lot of my noise effects. I’m currently exploring how I can reduce the amount of repetitive data being called from noises and operations by using HLSL. Checkout my Development Blog Post
